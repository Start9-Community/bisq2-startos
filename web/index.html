Bisq 2 Node

Your trusted node is running.

This is your own headless Bisq 2 node. The Bisq Connect mobile app pairs with it over Tor so you trade against a node you control instead of a stranger's.

Pair Bisq Connect

Open this service's Properties in StartOS. There you'll find the Pairing Code with a scannable QR — scan it from Bisq Connect, or copy it into More → Trusted node setup → Pair with a new trusted node. The code already encodes the node's onion address, so nothing else is needed.

Why the code isn't shown here: the pairing code grants trade control of your node, so it's surfaced only in the authenticated StartOS Properties view — never on this page. This page shows no secrets and can't act on your node.

Node status, health and backups are managed from the StartOS service dashboard.
